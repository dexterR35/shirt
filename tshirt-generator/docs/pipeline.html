T-SHIRT GENERATOR · HOW A KIT IS MADE

From the base photo to the download

The shirt photo (base.png) is never traced or redrawn. Each kit is validated SVG paint that gets multiplied into the photo's pixels, so the fabric folds, highlights and transparent edges stay exactly as photographed. The preview and every download use the same composite.

What “200 × 200 units” means

It's a drawing grid, not a pixel size. All kit paint (sleeves, stripes, collar) is drawn on a 200 × 200 square that covers the shirt: the shirt runs from about unit 2 at the collar to unit 198 at the hem. At render time the square is scaled to 7/8 of the image (a 1/16 margin on each side), so the same paint fits every size exactly.

Why quality is kept

  • Never enlarged. Every size, including 4096, scales the photo down, so no detail is invented.
  • Lossless where it counts. The master PNG, the lossless WebP screen copy, PNG downloads and WebP at quality 1 (VP8L).
  • The fabric isn't redrawn. Shading and edges come straight from the photo; only the color is multiplied in.
  • Paint is vector. The SVG paint is rasterized fresh at each size, so stripes and trims stay crisp.
  • AVIF is visually lossless, not bit-exact. Quality 95 with full color resolution (4:4:4) and exact transparency measures about 52 dB against the PNG, with files about a tenth of the size.
  • The page never waits. Decoding, compositing and encoding run in two render workers (screen and downloads), so the page keeps 60 fps even during a 4096 AVIF.
  • A ZIP doesn't recompress. Images are stored as they are, so it doesn't lose quality or waste time.

Where it lives in the code

  • scripts/prepare-png-base.mjs: master copy and the 2048 WebP crop
  • scripts/build-catalog.mjs: validates kits and layouts, writes public/catalog
  • src/lib/png-shirt.js: paint SVG (renderColorArtwork) and compositePixels
  • src/lib/png-preview.js: paint rasterizing, render cache, the two worker lanes
  • src/lib/render.worker.js: base decode, composite and PNG/WebP/AVIF encoding (OffscreenCanvas)
  • src/lib/composite.js: the paint area and the multiply, shared by page and worker
  • src/lib/export.js: sizes, shapes, formats, file names, ZIP
  • src/App.jsx: collection, yes/no question, batch downloads
