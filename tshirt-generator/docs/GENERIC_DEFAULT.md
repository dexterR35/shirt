# Default generic jersey

The user selected the green/dark-green oversized N design as the default generic
jersey on 13 October 2026. Its revision is `r005`.

- Canonical editable document: `data/generic-jersey.json`.
- Published copy: `public/catalog/generic-jersey.json`, regenerated by `npm run catalog:build`.
- Studio loader: `src/lib/generic-jersey.js`; configuration copies are validated and isolated from edits.
- Original fabric: unchanged 8000 × 5000 `base.png`, through `original-png-composite-1`.

Studio opens on this design in the original shirt canvas, replacing the white
startup shirt. There is no separate generic selector, toolbar or surface switch.
Choose **Edit** to customise it. The N motif has its own colour
control; shoulder paint follows the corresponding sleeve. Body, collar and cuffs
remain independently editable. Save applies the edits to that surface variant;
Reset all restores the JSON default. As with other Studio colour edits, changes
stay in memory until reload. The canvas **Download** button opens size, format and
shape options. **Download design JSON** in that panel saves the current configuration
and marks custom edits explicitly. Image downloads use the same displayed paint.

The JSON retains both surface variants for handoff, but Studio uses one default
green design on all preview backgrounds. **Clear team** beside the selected team
returns to this default, keeping saved colour edits for the session. A selected
team and variant still reopen on refresh; unavailable team kits still show the
plain base and missing-kit message. This document is separate from the 735-team researched catalog and
does not add a team, season or ready-kit claim. No Sports-site fallback mapping
is implemented here. Prior generic design revisions and their builders remain
available for reproduction.
